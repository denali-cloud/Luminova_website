# Luminova · sitio web

Sitio de [luminova.mx](https://luminova.mx), atención psicológica en línea.

Cada cambio que se sube a la rama `main` se publica solo en Cloudflare.

## Estructura

- `public/index.html` — página de inicio
- `public/aviso-de-privacidad/` — aviso de privacidad integral
- `public/entrevista/` — formulario de entrevista inicial
- `public/img/` — logo, imagen del cerebro y foto
- `wrangler.jsonc` — configuración de Cloudflare (no borrar)
